# Experience

## Feel

A calm study tool, like Notion or Anki: white background, one readable serif or clean sans
for questions, maths rendered properly, generous spacing, very little colour. (D8)
Colour carries meaning only: topic-map shading (one hue, light to dark), the amber "rough
guide" label, the red card for unchecked solutions.

## Screens

| Screen | Shows | Primary action | Empty state |
|---|---|---|---|
| Course search | Courses with paper counts | Open course | "Search a course code, like MA 109" |
| Topic map | Topics shaded by frequency, "Important, not asked yet" branch, paper count | Practise a topic | "No papers yet. Upload the first one." |
| Topic practice | Questions with scan snippets and figures | Mark done / hard | "No past questions on this topic yet" |
| Upload | Camera or PDF, course / year / exam type | Upload | - |
| Exam plan | 9 sessions over 3 days | Start session | - |
| My stuff | Uploads, marks, plans, share links | - | - |

## Words

- The map line: "How often a topic came up before. Any syllabus topic can be asked."
- Thin data: "Based on 2 papers: a rough guide."
- Unchecked solution card: "Not checked yet. From a senior's paper, it may contain
  mistakes. Try it yourself first."
- Never: "will be asked", "will come", "predicted", "sure shot", "guaranteed".
