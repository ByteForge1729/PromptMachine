# Exam-week plan

**Tier:** v0 · **Sources:** D14, D19, D2, A13, A28

## Behaviour
1. "Plan my 3 days" builds 9 sessions using the priority rule in 03-data-model.md.
2. Each session: 1–2 topics, 3–6 real past questions, about 90 minutes.
3. Day 3 includes one slot per "Important, not asked yet" topic.
4. Unverified or disputed material never appears in a plan.
5. Fewer than 3 papers: every session is labelled "based on N papers: a rough guide".

## Acceptance criteria
- [ ] Given a student who marked "Laplace" hard, then Laplace ranks above a topic with the
      same frequency.
- [ ] Given a course with 2 papers, then every session carries the rough-guide label.
- [ ] Given a hidden (misread) question, then it never appears in a plan.
