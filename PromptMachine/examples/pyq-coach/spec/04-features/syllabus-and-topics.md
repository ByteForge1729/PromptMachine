# Syllabus and topics

**Tier:** v0 · **Sources:** D7, D20, D23, D26, A26, A34

## Behaviour
1. First upload for a course with no syllabus asks the uploader to paste it from the course
   catalogue; a second student confirms before it is used.
2. When a syllabus changes, a new version is added with the year it takes effect. Papers
   are tagged against the version of their year.
3. Questions on topics no longer in the syllabus stay visible, labelled "no longer in
   syllabus", and never count.
4. The AI tags each question with 1 or 2 topics, and suggests which never-asked topics are
   fundamental; those are labelled "AI-suggested" with a "disagree?" button.

## Acceptance criteria
- [ ] Given an unconfirmed syllabus, then no topic map is shown for that course.
- [ ] Given a 2018 question on a topic dropped in 2022, then it is labelled and excluded from
      frequencies.
- [ ] Given any AI-suggested fundamental topic, then the "AI-suggested" label is visible.
